# SALTLINE（盐线）中文汉化版 —— 项目介绍

> 本作是在**原版 SALTLINE** 单文件 3D 网页游戏基础上进行**汉化**（本地化）的项目，将游戏中面向玩家的全部英文界面与文案翻译为中文，游戏逻辑与玩法保持原样。

---

## 一、项目背景

SALTLINE 是一款基于 **Three.js** 制作的第一人称 3D 网页游戏（"盐线码头"），玩家扮演港务局突入队员，在失控的港口安防系统中切断三条上行链路中继、躲避并击倒敌方机械单位，最终抵达船只撤离。

原版以单个 HTML 文件形式分发（内含压缩后的 Three.js 渲染引擎与完整游戏逻辑），游戏自带英文界面、HUD、叙事与场景标牌。本次汉化旨在**消除语言障碍**，让中文使用者可以直接上手，而**不修改任何游戏玩法、规则或技术实现**。

---

## 二、汉化内容

本汉化版将原版中**所有面向用户的英文**统一替换为中文，覆盖范围包括：

| 区域 | 汉化内容 |
| ---- | ---- |
| **开机画面** | 加载阶段提示（"正在唤醒渲染器""堆叠集装箱""启动吊机""就绪"等） |
| **主菜单** | 标题、副标题、背景故事、操作按钮（部署 / 设置 / 操作说明） |
| **暂停 / 阵亡 / 结算界面** | 继续、重试、再次部署、存活时间、命中率、评价等 |
| **设置面板** | 图形质量、鼠标灵敏度、视野、主音量、全屏（含"设置 / 操作说明"两个页签） |
| **操作说明** | 键盘 / 触屏 / 手柄 全部按键与手势提示 |
| **游戏内 HUD** | 目标、中继计数、生命值、弹药状态（换弹 / 弹匣已空 / 弹药不足）、击杀提示、罗盘方向（北 / 东北 / 东…）、敌袭警报 |
| **电台叙事** | 开场、遭遇、切断中继、撤离等全部无线电对白 |
| **世界场景标牌** | 危险、保持清空、柴油、缓行、仅限授权人员等地面与设备铭牌 |

---

## 三、汉化原则

1. **不改动逻辑**：仅替换用于显示的字符串，不触碰 `data-*` 属性、事件名、内部状态标识等游戏运行所依赖的逻辑键。
2. **保留专有名词**：游戏名 `SALTLINE`、船名 `KITTIWAKE`、编号 `B4` 等品牌 / 专有名词予以保留。
3. **保留技术标识**：如 `UN 1202`、`EUR`、`LPG`、`API 5L …` 等规格代号、吊机 ID、方向度数、按键符号（E / Shift / Esc）不属语言文本，维持原样。
4. **尊重原作**：仅在原作品与玩法不动的前提下做界面文案的中文本地化。

---

## 四、技术说明

- **交付形态**：单文件 HTML，双击即可在支持 WebGL 的现代浏览器中直接运行，无需联网下载或安装。
- **改动范围**：全部改动集中在面向用户的字符串字面量，未修改 Three.js 渲染引擎及游戏数值 / 玩法代码。
- **质量校验**：
  - 使用 Node 对脚本进行语法校验，**无语法错误**；
  - 在本地服务中实际加载运行，界面与 HUD 中文文案正常渲染，**无 JS 运行报错**。

---

## 五、使用说明

1. 用浏览器（Chrome / Edge / Firefox 等）打开 `SALTLINE-中文版.html`；
2. 点击 **部署** 开始游戏，点击 **设置** 可调节画质、灵敏度、视野等；
3. 支持键盘 / 触屏 / 手柄操作，具体按键见 **操作说明**。
